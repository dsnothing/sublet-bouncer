Claude Code, Codex and Antigravity/Gemini assisted concept/specification, backend and tests, data/evaluation tooling, frontend, browser checks and documentation through the farm workflow. Source files, fixtures and evaluation reports remain inspectable; AI-authored text and tests are not independent human validation.

The configured production chain is Gemini 3.1 Flash-Lite (`gemini-3.1-flash-lite`) → Flash (`gemini-3-flash-preview`) → offline rules. [api/gemini.ts:18](../api/gemini.ts#L18) defaults to the reverse provider order unless environment overrides are provided. Results expose the actual answering model, mode and fallback reason. Primary and fallback attempts have 14-second and 6-second budgets within a 20-second LLM deadline ([adapter:4](../api/gemini.ts#L4)); geocoding can add time. Live listing text is sent to Gemini. Unknown commute with an extracted address may trigger a server-side OpenStreetMap Nominatim query containing normalized address text, regional context and a generic app User-Agent, without user identity or the full listing ([API:14](../api/analyze.ts#L14), [geocoder:14](../api/_lib/geocode.ts#L14)). Explicit browser offline mode uses bundled extraction/data without those calls. See [accountability](ACCOUNTABILITY.md) for privacy and cache details.

Verified model clause proposals require a relevant, non-negated concept and remain tentative; suspected violations create blocking questions while informational topics remain ok with review notes ([engine:37](../core/engine.ts#L37), [escalations:125](../core/engine.ts#L125)). Deterministic rules, the fixed synthetic-trained scam model and action gate make downstream decisions. D5 defaults to applies without owner-sharing evidence; D4 unknown is non-blocking. Notes still block ICS ([decision map](DECISION-MAP.md)).

Automated checks include span/value verification, tests, source-excerpt verification and evaluation fixtures. Captured UI evidence documents agent-run checks. A separate AI reviewer authored blind red-team fixtures; that is model independence, not a human study.

Users must assess uncertain facts, review drafts and confirm allowed exports/copy actions. No messages are sent, payments made or leases signed by this app.
