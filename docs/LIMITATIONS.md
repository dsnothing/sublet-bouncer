# Limitations

- **Synthetic model/data:** the logistic scam model trains on seeded synthetic examples. Its score is uncalibrated and cannot establish a real-world fraud probability. Gold fixtures overlap the authors' rule knowledge. Frozen v2 measures pre-C2d/C2e code and subsequently became development data; it is not current-code validation. See [sources](DATA-SOURCES.md) and [evaluation](../evals/RESULTS.md).
- **Transit proxy:** the November 24, 2026 GRT weekday schedule is a current-term proxy for Winter 2027. Fixed departure and cached arrival times do not optimize a personal itinerary or reflect disruptions. Straight-line walks omit barriers and accessibility; same-stop transfers have no minimum buffer. See `data/transit_provenance.json` and the transit builder described in [sources](DATA-SOURCES.md).
- **Rent proxy:** CMHC/Statistics Canada values are means, despite the compatibility key `median_monthly`. Room rent is half a two-bedroom mean, not a measured room median or today's asking rent.
- **Geocoding:** 16 cached entries cover only selected Waterloo-area locations. Some are streets/places, not verified civic addresses. In live-request mode, unknown commute with an extracted address can trigger a server-side OpenStreetMap Nominatim query; normalized address text plus regional context leaves our server, without user identity or full listing ([API:14](../api/analyze.ts#L14), [geocoder:14](../api/_lib/geocode.ts#L14)). The cache/one-request-per-second queue is per process, not global, and failed lookups are cached too. A returned coordinate still needs a bundled route within 600m. Unknown commute is a non-blocking note and blocks ICS; a missing extracted address is blocking ([engine:115](../core/engine.ts#L115), [fallback:135](../core/engine.ts#L135)). Aliases, first-result coordinates and nearest origins remain approximate. Explicit browser offline mode cannot extend the bundled cache.
- **English and Ontario only:** input refusal uses language heuristics, not reliable language identification. Plain/simple English display does not add multilingual analysis. Ontario rules cover selected issues; other jurisdictions and legal exceptions are outside scope ([core/injection.ts](../core/injection.ts)).
- **Quota and latency:** Gemini 429/503 responses and timeouts can cause a fallback model or offline rules. The adapter budgets 14 seconds for primary and 6 for fallback within 20 total ([api/gemini.ts](../api/gemini.ts)). This is an LLM deadline, not an end-to-end latency guarantee: geocoding has a queue wait and up to five seconds of fetch time. Neither model fallback nor a successful demo establishes sustained reliability. Offline extraction can miss paraphrased restrictions; inspect the mode and evidence before relying on ADMIT.
- **Dated legislation:** [RTA verification](../data/RTA-VERIFICATION.md) records retrieval on November 24, 2026. Archived excerpts do not verify future amendments. D5 defaults to applies when owner residence/sharing evidence is absent. Owner residence without explicit separate kitchen and bathroom triggers may_not_apply and a blocking question; this proxy can miss or overstate sharing ([engine:52](../core/engine.ts#L52)). Sharing kitchen/bath is only one applicability exception; patterns can miss negation, voluntary payments and context. Not legal advice.
- **Trust and recovery:** no ownership, identity or listing authenticity verification. ADMIT means no implemented check blocked the listing. Undo restores local state, not external clipboard/download effects; logs and localStorage are editable by the browser user.
- **Post-v3 C10:** The jurisdiction guard is pattern-based and can miss or misread locations; the safety suite uses authored development data. Frozen v3 did not evaluate C10.
